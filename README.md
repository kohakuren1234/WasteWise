# WasteWise

**WasteWise** is a web application designed to help users manage and reduce waste efficiently. The platform allows users to track, sort, and properly dispose of different types of waste while promoting environmentally responsible habits.  

## Features
- User-friendly interface for waste management  
- Information on proper disposal of different waste types  
- Static and interactive content with images and guides  
- Built with Node.js, Express, and SQLite  

## Technologies Used
- **Backend:** Node.js, Express.js  
- **Database:** SQLite  
- **Frontend:** HTML, CSS, JavaScript
